# EduGenie – Google Gemini Powered Learning Assistant

EduGenie is an AI-powered learning assistant designed to help students learn faster and more effectively using Google Gemini.

## 🚀 Features

- 💬 AI Q&A – Get concise answers to questions.
- 📖 Simplified Explanations – Understand difficult concepts in simple language.
- 📝 Quiz Generation – Generate quizzes from a given topic.
- 🛣️ Personalized Learning Paths – Create structured learning paths from beginner to advanced.
- 📄 Text Summarization – Summarize long passages into key points.
- 🎯 Learning Recommendations – Get personalized suggestions for further learning.

## 🛠️ Technologies Used

- Python
- FastAPI
- Google Gemini API
- HTML
- CSS
- Jinja2
- Uvicorn
